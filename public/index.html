About This Project & Architecture

College Full Stack Development (FSD) Coursework

🎨 Frontend Layer

Built using semantic HTML5, responsive CSS3, and Vanilla JavaScript. Uses native fetch() API for asynchronous HTTP communication with the Express backend.

⚙️ Backend Layer

Powered by Node.js and Express.js. Provides clean REST API endpoints for GET, POST, and DELETE operations, input validation, and JSON response formatting.

🗄️ Database Layer

Cloud-hosted MongoDB Atlas database named stock_watchlist. Mongoose ODM enforces schema models, data types, and unique constraints for ticker symbols.

🔒 Security & Best Practices

Environment variables stored in .env using dotenv, unique indexing to prevent duplicate stocks, CORS support, and safe DOM manipulation to prevent XSS vulnerabilities.
